# Kata15: A Diversion

Source: http://codekata.com/kata/kata15-a-diversion/

## Problem

A diversion kata — the problem is intentionally vague. The goal is to practice dealing with ambiguity and finding your own direction.

This is a **design kata** / **open-ended kata** — no specific coding required.

## Goals

- Practice problem discovery
- Define your own success criteria
- Explore without a fixed target

## Suggestions

1. Pick something you've always wanted to build
2. Set a time limit (2 hours, 1 day, 1 week)
3. Document your process: decisions, dead ends, pivots
4. Reflect: what did you learn about how you work?

## Possible Directions

- A tiny game (snake, tetris, roguelike)
- A useful CLI tool
- A data visualization
- A programming language subset
- A protocol implementation
- A puzzle solver

The point is the **process**, not the product.
